# Запуск без денег: GitHub + Supabase + Render

Всё ниже бесплатно. Займёт около 40 минут. Порядок важен.

## Как это работает бесплатно

Бесплатный сервер на Render засыпает, если к нему 15 минут никто не обращался, и просыпается около минуты. Поэтому:

- Бот работает через **вебхук**: Telegram сам стучится на сервер и будит его. Ответ на `/start` после сна приходит с задержкой до минуты.
- Пока игрок в игре, сервер не спит, поэтому покупки за Stars проходят нормально.
- Чтобы сервер не засыпал совсем, его раз в 10 минут «пингует» бесплатный сервис cron-job.org (шаг 6). Бесплатных 750 часов в месяц хватает на один сервис без перерыва.

## Шаг 1. Бот в Telegram

1. Открой @BotFather, отправь `/newbot`, придумай имя («Донер у Маги») и username (должен заканчиваться на `bot`).
2. Скопируй токен вида `123456:ABC...`. **Никому его не отправляй**, он понадобится на шаге 5.
3. Узнай свой Telegram ID: напиши боту @userinfobot, он ответит числом. Это `ADMIN_IDS`.

## Шаг 2. GitHub

1. Зарегистрируйся на github.com.
2. Нажми **New repository**, имя `shawarma-empire`, выбери **Private**, нажми **Create repository**.
3. На странице пустого репозитория нажми ссылку **uploading an existing file**.
4. Распакуй архив и перетащи **содержимое** папки `shawarma-empire` (папки `server`, `public`, `shared` и файлы `package.json`, `render.yaml` и остальные) в окно браузера. Нажми **Commit changes**.

Проверь: в корне репозитория должны лежать `package.json` и `render.yaml`, а не одна папка `shawarma-empire`.

## Шаг 3. База Supabase

1. Зарегистрируйся на supabase.com, нажми **New project**.
2. Регион выбери ближайший к Казахстану из предложенных. Пароль базы придумай и сохрани.
3. Когда проект создастся, открой **SQL Editor**, вставь весь текст файла `db/schema.sql` и нажми **Run**.
4. Открой **Project Settings → API** (или **API Keys**). Скопируй **Project URL** и секретный ключ **service_role** (в новом интерфейсе он может называться **secret**). Публичный `anon` ключ не подходит.

## Шаг 4. Render

1. Зарегистрируйся на render.com через кнопку **GitHub**.
2. Нажми **New → Blueprint**, выбери репозиторий `shawarma-empire`. Render прочитает `render.yaml` и предложит создать сервис на бесплатном тарифе.
3. Он попросит заполнить переменные. Пока впиши всё, кроме `WEBAPP_URL`:

| Переменная | Что вписать |
| --- | --- |
| `BOT_TOKEN` | Токен из шага 1 |
| `ADMIN_IDS` | Твой Telegram ID |
| `SUPABASE_URL` | Project URL из шага 3 |
| `SUPABASE_SERVICE_KEY` | Секретный ключ из шага 3 |
| `SUPPORT_CONTACT` | Твой @username для вопросов по оплате |
| `WEBAPP_URL` | Оставь пустым, заполним на шаге 5 |

4. Нажми **Apply**. Первый запуск упадёт с ошибкой «Для TG_MODE=webhook нужен WEBAPP_URL». Так и должно быть.

## Шаг 5. Адрес игры

1. Вверху страницы сервиса Render показывает адрес вида `https://shawarma-empire-xxxx.onrender.com`. Скопируй его.
2. Открой **Environment**, впиши его в `WEBAPP_URL` **без слэша в конце**, сохрани. Сервис перезапустится.
3. В логах (**Logs**) должно появиться `Бот @твой_бот запущен (вебхук)` и `база: supabase`.

## Шаг 6. Чтобы сервер не засыпал

1. Зарегистрируйся на cron-job.org.
2. Создай задание: адрес `https://твой-адрес.onrender.com/healthz`, интервал каждые 10 минут.

## Шаг 7. Проверка

1. Открой своего бота, нажми `/start`, потом **Играть**. Пройди опрос, потапай, купи уровень.
2. Отправь боту `/stats`: должна прийти статистика с одним игроком.
3. Проверь оплату: купи в магазине стартовый набор за 25 Stars. Номер платежа (`charge_id`) найдёшь в Supabase: **Table Editor → purchases**. Отправь боту `/refund <charge_id>`, и звёзды вернутся. Делай это до запуска рекламы.

## Если что-то пошло не так

- **Render просит банковскую карту.** Правила бесплатных тарифов часто меняются. Напиши мне, подберём другой вариант.
- **Бот молчит.** Открой Logs на Render. Чаще всего ошибка в токене или в `WEBAPP_URL` (лишний слэш, `http` вместо `https`).
- **Игра пишет «Открой игру через Telegram».** Ты открыл адрес в обычном браузере. Игра работает только из кнопки в боте.
- **Изменил код.** Загрузи изменённые файлы в GitHub так же, как в шаге 2. Render пересоберёт сервис сам.

## Когда появятся первые деньги

Бесплатный сервер слабый (0,1 процессора, 512 МБ памяти). На первые сотни игроков его хватит. Когда игроков станет больше или начнутся задержки, переходи на платный тариф без сна.
